## Description (champ principal)

Boxes est un organisateur de bureau pour Windows. Crée autant de boîtes que tu veux, personnalise leur apparence, glisse-y tes fichiers et raccourcis — et ton bureau redevient respirable. Aucun compte, aucun abonnement, aucune prise de tête.

---

✨ FONCTIONNALITÉS

- Boîtes flottantes redimensionnables et déplaçables librement
- Gestionnaire central pour créer, ouvrir et organiser toutes tes boxes
- Glisser-déposer depuis le bureau, l'explorateur, ou entre boîtes
- Panneau **Apparence** (🎨) en fenêtre dédiée : couleur, opacité, extensions de fichiers, rangement du bureau
- Rouler / dérouler une box en double-cliquant sur sa barre de titre
- Tri des éléments par nom, type, date de modification ou ordre d'ajout
- Ranger le bureau automatiquement : les fichiers glissés depuis le bureau sont rangés dans un sous-dossier dédié
- Aperçu automatique des fichiers PDF, Word, Excel, PowerPoint, Photoshop…
- Icônes personnalisables par élément
- Taille d'icônes réglable (32, 48, 128, 256 px)
- Raccourci **Ctrl+Alt+Espace** pour afficher ou masquer toutes les boxes
- Démarrage automatique avec Windows (optionnel)
- Icône dans la zone de notification (systray) avec accès rapide à chaque box
- Duplication de boîte en un clic
- Export / Import des icônes personnalisées
- Mises à jour automatiques (via GitHub Releases)
- 100 % local — aucune donnée envoyée, aucun compte requis

---

🖥️ PRÉREQUIS

- Windows 10 ou Windows 11
- Aucune installation de runtime requise
