🚀 Gestion des boxes
+ Cliquez sur Nouvelle Box pour créer un groupe
clic Cliquez sur une box dans cette liste pour l'ouvrir ou la mettre au premier plan
✏️ Cliquez sur le titre d'une box pour la renommer directement
🗑️ Supprimez une box depuis cette fenêtre — les fichiers sont envoyés à la corbeille
⊞ Bouton taille dans cette liste : choisissez la taille des icônes par box (32 / 48 / 60 px)
📁 Gestion des fichiers
Drag Glissez-déposez des fichiers ou dossiers depuis l'explorateur Windows dans une box — ils sont copiés automatiquement
Drag Déplacez un fichier d'une box à une autre par glisser-déposer inter-boxes. Si plusieurs fichiers sont sélectionnés (Ctrl+clic ou rectangle), ils se déplacent tous en même temps
Drag Glissez un fichier depuis une box vers le bureau ou l'explorateur Windows pour le déplacer hors de la box
⇄ Ordre manuel — en mode tri "Ordre original", glissez une icône sur une autre pour la réorganiser. L'ordre est sauvegardé automatiquement
2×clic Double-cliquez sur un fichier pour l'ouvrir avec son application par défaut
Suppr Touche Suppr : envoie le(s) fichier(s) sélectionné(s) à la corbeille
Ctrl+A Sélectionner tous les fichiers de la box
⬚ Cliquez-glissez sur le fond de la box pour sélectionner plusieurs fichiers à la fois (rectangle de sélection)
🖱️ Menu contextuel (clic droit)
Ouvrir Ouvre le fichier avec son application par défaut
📂 Ouvrir le dossier — révèle le fichier dans l'explorateur Windows
📋 Copier sur le bureau — copie le fichier sans le retirer de la box
↗ Déplacer sur le bureau — extrait le fichier de la box vers le bureau
✏️ Renommer — modifie le nom du fichier directement dans la box
🖼️ Changer l'icône… — assignez une image personnalisée (PNG, JPG, ICO) à un fichier dont l'icône est générique ou manquante
↺ Réinitialiser l'icône — restaure l'icône système d'origine
🗑️ Supprimer — envoie le fichier à la corbeille
🎨 Personnalisation des boxes
🎨 Bouton palette dans chaque box : choisissez la couleur de fond (presets ou couleur libre) et l'opacité
2×clic Rouler / dérouler — double-cliquez sur la zone vide de la barre de titre pour réduire la box à sa barre de titre. Double-cliquez à nouveau pour la rouvrir à sa taille d'origine. L'état est sauvegardé automatiquement
⇅ Bouton tri : classez les fichiers par Nom, Type, Date de modification ou ordre d'ajout original — cliquez deux fois sur le même critère pour inverser l'ordre
ext. Afficher les extensions — toggle dans le panneau 🎨 : affiche ou masque les extensions de fichiers (.pdf, .docx…) sous chaque icône. Les fichiers système (.lnk, .exe, .url…) sont toujours affichés sans extension
↔↕ Redimensionnez une box en tirant le coin bas-droit
drag Déplacez une box en faisant glisser sa barre de titre
🗂️ Ranger le bureau automatiquement
🎨 Option Ranger le bureau dans le panneau 🎨 de chaque box (activée par défaut)
auto Quand vous glissez un fichier depuis le bureau dans une box, l'original est automatiquement déplacé dans un sous-dossier du bureau portant le nom de la box
ex. Un fichier glissé dans la box Projets déplace l'original dans Bureau\Projets\ — le bureau reste propre
off Désactivez l'option si vous préférez que l'original reste à sa place sur le bureau
🖼️ Aperçus & icônes
PDF Miniature de la première page générée automatiquement
PSD Aperçu extrait du fichier Photoshop sans ouvrir l'application
.lnk Raccourcis Windows : icône résolue depuis la cible (Office, Adobe, etc.)
.url Favoris web : icône colorée générée depuis le nom de domaine
img Images (JPG, PNG, GIF, WebP…) : miniature native affichée directement
vidéo Vidéos et fichiers Adobe (Premiere, After Effects, InDesign…) : aperçu Shell Windows
⌨️ Raccourci clavier global
Alt+Espace Afficher / masquer toutes les boxes — fonctionne depuis n'importe quelle application, même quand Boxes est en arrière-plan. Appuyez une fois pour masquer toutes les boxes, appuyez à nouveau pour les faire réapparaître
🔔 Icône dans la barre des tâches (tray)
clic Clic gauche sur l'icône Boxes dans la zone de notification — affiche ou masque le gestionnaire
clic ⊞ Clic droit — ouvre un menu avec accès direct à chaque box, "Tout afficher", "Tout masquer" et "Quitter"
✕ Le bouton ✕ du gestionnaire masque la fenêtre dans le tray — l'app continue de tourner
⏻ Le bouton ⏻ du gestionnaire quitte complètement Boxes
💾 Stockage & démarrage
📂 Les fichiers sont copiés dans C:\Users\[vous]\AppData\Roaming\Boxes\fences\
🖼️ Les icônes personnalisées sont stockées dans C:\Users\[vous]\AppData\Roaming\Boxes\custom-icons\
↺ Positions, tailles et styles de chaque box sauvegardés automatiquement
⏵ Bouton démarrage automatique (vert = actif) — Boxes se lance avec Windows
